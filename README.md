# White Language for VS Code

This extension provides syntax highlighting and other basic VS Code support for
White Language. Completion is not available yet.

Use the play button in the editor title bar to compile and run the current
White Language file. The extension finds `wlc` through
`whitelanguage.compiler.path` or `WL_PATH/bin/wlc`.

## Finding `wlls`

1. `whitelanguage.server.path`
2. `WL_PATH/bin/wlls` (`wlls.exe` on Windows)

## Development

```sh
npm install
npm run compile
npm run check
npm run package
```

`out/` is generated by `npm run compile` and is not committed.
